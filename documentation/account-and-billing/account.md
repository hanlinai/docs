# Account

This page explains how to create and manage your Engy account. It is intended for users who are setting up access to Engy.

## Create an account

You can sign up at [engy.ai/signup](https://engy.ai/signup) with one of the following methods:

| Method | Description |
| --- | --- |
| Email and password | Enter your email address and a password. Then open the verification email and confirm your address. |
| Google | Sign in with your Google account. |
| GitHub | Sign in with your GitHub account. |

If you sign in with Google or GitHub using the same email address as an existing account, Engy links the sign-in method to that account.

{% hint style="info" %}
If you sign up with an email address, you must verify it before you can sign in.
{% endhint %}

## Sign in

Go to [engy.ai/login](https://engy.ai/login) and sign in with the method that you used to sign up. After you sign in, the dashboard opens.

## Manage your password

| Task | Steps |
| --- | --- |
| Reset a forgotten password | On the sign-in page, select the forgot password option and follow the instructions in the email. |
| Change your password | In the dashboard, go to **Settings** and use **Change password**. |

## Account structure

Each account has its own credit balance, API keys, and account token. Engy does not support organizations or shared team accounts. To separate workloads within one account, create multiple API keys with different labels.
